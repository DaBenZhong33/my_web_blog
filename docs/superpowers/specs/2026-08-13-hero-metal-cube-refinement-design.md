# 首页金属立方体整体优化设计

## 背景

首页首屏右侧当前使用 `HeroMetalCube.vue` 渲染一个由六个独立面片组成的 Three.js 金属立方体。现有实现已经具备默认旋转、悬停展开、触控触发、减少动画偏好、WebGL 降级和资源释放，但实际画面偏暗、材质层次不足，白色边线较强，整体更像线框模型；旋转和展开节奏也较机械，桌面与移动端构图仍有提升空间。

本次优化不改变首页信息架构，集中提升立方体的材质、灯光、交互动势和响应式构图。

## 已确认方向

- 主气质结合“精密工业体”和“机械解构核心”。
- 默认状态保持完整封闭，第一眼稳定、克制。
- 交互后显露内部核心和结构关系，形成明显但不失秩序的反差。
- 展开使用精密机械动势：六个面错峰展开，带轻微阻尼回弹。
- 不采用高饱和光谱液态金属，也不让默认状态持续留缝或爆开。

## 目标

- 让立方体在默认状态下具有清晰的金属体积、分面和环境反射。
- 弱化线框感，建立由材质和灯光形成的轮廓。
- 让展开交互更有层次、机械秩序和记忆点。
- 平衡立方体与左侧标题的视觉重量，改善移动端留白。
- 保持现有性能、无障碍降级和生命周期清理能力。

## 非目标

- 不重做首页背景、文案、导航、按钮或其它区块。
- 不引入新的 3D 引擎、动画库、后期处理管线或外部纹理资源。
- 不增加声音、粒子系统、物理模拟或可自由拖拽的 3D 控制器。
- 不将立方体改成持续展开的装置形态。

## 视觉与材质

默认形态使用深钛银拉丝金属。顶面偏亮、正面中灰、侧面偏深，通过灯光方向和环境反射建立稳定的明暗分面。现有白色边线改为更窄、更低透明度的冷白轮廓，只负责补足极暗角度下的形体识别，不再成为主体视觉。

拉丝纹理继续由 Canvas 生成，但纹理层次拆分为细密横向拉丝、少量不规则亮纹和更柔和的面内明暗变化。环境反射增加窄条高亮与深色区，使立方体旋转时出现缓慢移动的条状流光。材质保持偏粗糙的工业金属，不追求镜面铬效果。

荧光黄仅用于内部核心、闭合缝隙的极弱漏光和展开时短暂出现的连接线。默认状态几乎看不到核心，展开后核心亮度上升，成为互动状态的视觉焦点。

## 灯光与场景

场景使用一盏偏上方的柔和主光塑造顶面，一盏低强度冷白填充光保留暗部细节，以及一盏荧光黄轮廓光呼应站点色彩。环境纹理承担主要金属反射，灯光只补充体积，不制造大面积过曝。

相机继续使用透视相机。桌面端适当缩小立方体并上移，使其视觉中心与标题中部对齐；平板和手机分别使用独立的相机距离与组件尺寸。移动端确保立方体不压住按钮，且底部不被首屏裁切。

## 动效与交互

默认旋转速度降低，使用稳定的展示台式转动，并保留幅度很小的上下浮动。鼠标位置只影响轻微的视角偏移，使用平滑插值，不改变展开路径。

鼠标进入后先降低整体旋转速度，再按“前后面、左右面、上下面”的顺序错峰展开。每个面沿自身法线推出，并叠加小幅独立旋转。动画到位时使用克制的阻尼回弹，不产生夸张弹跳。内部核心随总展开进度由暗到亮，六条连接核心与面片的荧光黄细线在中后段显现。

鼠标移开后按照反向顺序合拢。连接线和核心先降低亮度，面片闭合后整体旋转恢复默认速度。触屏点击播放一次完整的展开、短暂停留和合拢序列，连续点击重置停留计时但不重复创建动画。

减少动画偏好启用时，保持完整闭合的静态立方体，不执行旋转、浮动、视角跟随或展开动画。

## 实现方案

继续在 `src/components/HeroMetalCube.vue` 内完成升级，不引入新依赖。保留六个独立 `PlaneGeometry` 面片，为每个面记录展开顺序、闭合变换和展开变换。

动画循环维护以下相互独立的状态：

- 整体旋转与轻微浮动；
- 指针视角目标与当前视角；
- 总展开目标；
- 每个面根据总进度和自身延迟计算的局部展开进度；
- 核心与连接线的亮度。

每个面的局部进度由统一时间轴加错峰延迟计算，避免创建多个定时器。触控仅使用现有的单个停留计时器。连接线使用轻量的 `LineSegments` 或独立线段集合，并在每帧根据面片位置更新端点。

`src/views/HomeView.vue` 只调整 `.hero-cube` 在桌面、平板和手机断点下的位置与尺寸。WebGL 初始化失败时保留 CSS 降级图形，并同步为深钛银、弱边线和荧光核心的视觉。

## 错误处理与资源管理

- WebGL 初始化失败时继续显示 CSS 降级图形。
- `ResizeObserver` 不可用或容器尺寸暂时为零时不执行无效渲染，并在后续有效尺寸更新时恢复。
- 组件卸载时取消动画帧和触控计时器，移除媒体查询监听，断开尺寸观察器。
- 释放面片、边线、核心、连接线的几何体和材质，以及 Canvas 纹理、渲染器和 WebGL 上下文。
- 不在渲染循环中创建新的几何体、材质、颜色或向量对象。

## 验证标准

- 默认桌面截图中，立方体具有明确的顶面、正面、侧面层次，不再呈现主要由白线定义的线框感。
- 悬停后六个面按三组错峰展开，核心和连接线可见，且不覆盖左侧标题和按钮。
- 鼠标移开后所有面准确闭合，不残留缝隙或连接线。
- 移动端立方体完整可见，不遮挡按钮，不超出首屏底部。
- 触控可完整播放一次展开和合拢；连续点击不会产生多个竞争计时器。
- 减少动画偏好下画面保持静态闭合。
- WebGL 降级图形仍可识别为钛金属立方体。
- 浏览器控制台无新增错误，首页结构验证与生产构建通过。
- 修改文件能够以 UTF-8 正常读取，乱码标记扫描无匹配。

## 预计修改范围

- `src/views/HomeView.vue`
- 必要时小幅更新 `scripts/verify-homepage-structure.mjs`

不修改项目数据、其它页面或全局信息架构。
