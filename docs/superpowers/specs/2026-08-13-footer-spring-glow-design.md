# 页脚弹簧光效设计

## 背景

用户希望把 21st.dev 的 Ruixen Gradient Footer 效果用于当前个人作品站，但不想替换现有页脚。新的交互要求是：原来的页脚保持不动，用户滑到原页脚后继续向下滚动，才出现彩色光效；往回滚动时，光效像弹簧一样收回。

当前项目是 Vue 3 + Vite，入口布局在 `src/App.vue`，全局样式在 `src/style.css`，组件放在 `src/components/`。现有页脚已经包含品牌、描述、GitHub、Email、即刻和版权信息，应继续保持可读和稳定。

附件提供的是 React + TypeScript 组件，依赖 shadcn/Tailwind 的项目约定。当前项目没有 React、Tailwind、shadcn 或 TypeScript，因此实现应转成 Vue 单文件组件和普通 CSS。

本次升级把原有“连续跟随尾部滚动”的展示方式改为带阈值的抽屉式交互：页脚光效被拉出但没有达到阈值时会回弹隐藏，达到阈值后会完整展开；完整展开后，各条状体开始稳定、柔和的随机呼吸律动。

## 目标

- 保留 `App.vue` 里现有 `.footer` 的内容、结构和主要样式。
- 保留原页脚后的短尾部区域，但不再用它的可见比例直接控制光效进度。
- 页面抵达底部后，继续向下输入才让光效从视口底部升起；反向输入时带阻尼地收回。
- 使用 SVG 和 CSS/JavaScript，不新增 React、Tailwind、shadcn 或 TypeScript。
- 光效只作为装饰层，不承载任何关键信息。
- 支持 `prefers-reduced-motion: reduce` 降级。
- 修改后检查 UTF-8 和中文乱码问题。
- 桌面滚轮和移动端触控拖动使用一致的拉起、吸附与收回规则。
- 拉起超过 `65%` 后吸附到完全展开，未达到阈值则回弹隐藏。
- 完全展开后，每根条状体以不同但可复现的周期、幅度和相位缓慢呼吸。

## 非目标

- 不把附件中的 `ruixen-gradient-footer.tsx` 原样复制到项目里。
- 不创建 `/components/ui`，因为这是 shadcn/React 结构，不符合当前 Vue 项目。
- 不改造现有 footer 链接、品牌、版权文字或信息架构。
- 不依赖浏览器原生 overscroll 橡皮筋行为。该行为在 Windows 和桌面 Chrome 上不稳定。
- 不让光效覆盖首屏、项目区或其它页面内容。
- 不在页面尚未到达底部时拦截滚轮或触控输入。
- 不使用每帧随机数驱动律动，避免条状体抖动和不可复现的视觉噪声。

## 用户体验

页面正常滚动到现有页脚时，用户先看到与当前站点一致的页脚和尾部区域，此时彩色光带保持隐藏。页面抵达底部后继续向下滚轮或触控上拉，光带才开始从视口底部逐渐升起。

用户反向输入时，光带按输入量收回；停止在中途时根据阈值吸附到隐藏或完全展开，不会长期停留在半展开状态。

在减少动画偏好下，不运行弹簧循环和随机呼吸；输入结束后直接切换到对应端点。

升级后的交互分为四个状态：

- `hidden`：组件收起，页面保持正常滚动。
- `pulling`：页面已经到达底部，继续向下滚轮或触控上拉会逐渐拉出组件。
- `expanded`：拉出进度超过 `65%` 并停止输入后，组件弹性吸附到完全展开。
- `collapsing`：完全展开后向上滚轮或触控下拉，组件先随输入收回；停止输入后按同一阈值决定恢复展开还是完全隐藏。

滚轮停止约 `150ms`，或触控结束时进行吸附判断。低于 `65%` 的拉起进度回弹到 `hidden`，达到或超过 `65%` 则吸附到 `expanded`。只有端点吸附动画结束后才算状态切换完成。

当组件处于 `expanded` 时，九根条状体开始随机呼吸。随机参数在组件初始化时由条状体索引经过确定性公式生成，因此每根柱子的速度、幅度和相位不同，但刷新和重渲染时不会出现突变。律动保持低幅、慢速，不能改变整体中间高、两侧低的轮廓识别。

## 组件设计

修改现有组件：

- `src/components/FooterSpringGlow.vue`

组件职责：

- 渲染 footer 后的尾部滚动空间。
- 渲染固定在视口底部的 SVG 光带。
- 根据页底状态和滚轮、触控输入计算拉起进度。
- 用 `requestAnimationFrame`、速度值和阻尼参数让实际进度追随目标进度。
- 在组件卸载时移除事件监听并取消动画帧。
- 监听 `prefers-reduced-motion`，必要时关闭动态追随。
- 只在页面抵达底部且用户继续向下输入时接管滚轮或触控拖动。
- 管理 `hidden`、`pulling`、`expanded`、`collapsing` 四个状态。
- 在完全展开时启动条状体随机呼吸，离开展开状态时停止呼吸。

`App.vue` 接入方式：

- 保持现有 `<footer class="footer">...</footer>` 不变。
- 在 footer 之后添加 `<FooterSpringGlow />`。
- 根 `.site` 和 `main` 的 flex 布局保持现状。

建议 props：

- `tailHeight`：尾部区域高度，默认 `38vh`。
- `minReveal`：保留为可选的视觉下限，但默认隐藏端点仍为 `0`。
- `snapThreshold`：端点吸附阈值，默认 `0.65`。
- `settleDelay`：滚轮停止后进行吸附判断的延迟，默认约 `150ms`。

首版可以只使用默认值，不暴露复杂调参。

## 光效实现

光带延续 Ruixen Gradient Footer 的核心视觉：多个模糊矩形柱组合成中间高、两侧低的彩色光幕。Vue 组件中保留这些稳定常量：

- viewBox 宽高：`1271 x 599`
- stops：暗红、蓝、浅蓝、近白、黄、红橙、品红、透明粉
- bars：默认 9
- blur：默认 15
- peak：默认 0.98
- valley：默认 0.55

`bellHeights` 作为普通 JS 函数保留，用于生成每个柱子的高度。SVG 使用唯一 id，避免同页多个渐变或滤镜冲突。

## 滚动与弹簧算法

组件先判断页面是否抵达底部，再把被接管的输入增量归一化为 `0–1` 的拉起进度。尾部容器的位置只用于确认交互区域已经到达，不再直接映射为光效进度。

实际显示进度使用弹簧追随：

- 保存 `current`、`target`、`velocity`。
- 每帧计算 `force = (target - current) * stiffness`。
- `velocity = (velocity + force) * damping`。
- `current += velocity`。
- 当 `current` 和 `target` 足够接近时停止动画帧。

光带样式由 CSS 变量驱动：

- `--footer-glow-progress`
- `--footer-glow-opacity`
- `--footer-glow-lift`

主要变换使用 `transform: scaleY(...) translateY(...)`，避免频繁改布局属性。

### 输入接管与吸附

页面未到达底部时不拦截任何滚轮或触控输入。页面到达底部后：

- 向下滚轮或触控上拉增加组件展开进度，并阻止这部分已经用于拉起组件的默认滚动。
- 完全展开后，继续向下输入不再累积进度。
- 向上滚轮或触控下拉减少展开进度；组件完全隐藏后，后续向上输入恢复页面正常滚动。
- `wheel` 输入使用短延迟定时器识别一次滚轮手势的结束；`touch` 输入在 `touchend` 或 `touchcancel` 时结束手势。
- 输入结束时，以 `0.65` 为吸附分界，将目标进度设为 `0` 或 `1`，沿用弹簧积分器完成回弹。

事件监听需要满足浏览器约束：需要调用 `preventDefault()` 的 `wheel` 和 `touchmove` 监听不得使用 `passive: true`；普通 `scroll`、`resize` 监听仍保持被动。触控逻辑记录最后一个触点的纵坐标，以相邻移动差值更新进度，并避免多指手势误触发。

### 随机呼吸

每个条状体预先获得一组确定性参数：

- 幅度约为自身基础高度的 `2%–7%`。
- 周期约为 `2.8–5.2s`。
- 相位错开，避免九根柱体同时到达波峰。
- 使用平滑正弦或等价缓动函数，不在动画帧中调用 `Math.random()`。

呼吸变换只作用于单根条状体的纵向尺度，并以底部为变换原点。整体展开进度仍由外层光带控制，两层变换互不干扰。只有状态稳定为 `expanded` 时添加律动类；进入 `pulling` 或 `collapsing` 后立即移除。

## 响应式与性能

桌面端：

- 尾部区域默认约 `38vh`。
- 光带固定在视口底部，`pointer-events: none`。
- SVG 不捕获焦点，不影响返回顶部按钮和 footer 链接。

移动端：

- 尾部区域可降低到约 `30vh`。
- 光带透明度降低，避免遮挡 footer 后的收尾感。
- 不改变现有 footer 在窄屏下的换行规则。

性能：

- 不使用 canvas 或 WebGL。
- 只在滚动目标变化或弹簧尚未稳定时运行动画帧。
- `scroll` 和 `resize` 监听使用 `{ passive: true }`；需要阻止默认行为的 `wheel` 和 `touchmove` 使用非被动监听。
- 端点吸附沿用单一 `requestAnimationFrame` 弹簧循环，不为每根条状体建立 JavaScript 动画循环。
- 随机呼吸使用 CSS 动画和每根柱体的 CSS 自定义属性实现。
- 只在可能接管输入时执行轻量的页面底部判断。

## 可访问性

- 光效根节点使用 `aria-hidden="true"`。
- 尾部区域不包含可聚焦元素。
- 减少动画偏好下关闭弹簧动画。
- 减少动画偏好下关闭随机呼吸，并把吸附切换为无振荡的端点更新。
- 原 footer 链接保持原有可访问性和键盘访问行为。

- 用 UTF-8 读取 `src/App.vue`、`src/components/FooterSpringGlow.vue` 和修改过的样式文件。
- 搜索常见乱码标记，确认中文没有乱码。
- 确认 `public/favicon.png` 等已有用户改动未被覆盖。

浏览器检查：

- 页脚内容与修改前一致。
- 到达页脚时光效不抢先覆盖内容。
- 继续向下滚动时光效升起。
- 往上滚动时光效弹性收回。
- 移动端没有横向溢出。
- 减少动画偏好下页面仍可用。
- 未到页面底部时，滚轮和触摸滚动行为与修改前一致。
- 在底部拉出不足 `65%` 并停止时，组件完整回弹隐藏。
- 在底部拉出达到 `65%` 后，组件完整吸附展开。
- 完全展开后九根条状体以不同节奏缓慢呼吸，没有跳变或同步起伏。
- 展开后反向输入可先收回组件，隐藏后继续正常向上滚动页面。

## 自检

- 设计明确保留原 footer，不替换现有页脚。
- 设计明确使用 footer 后的短尾部滚动区，不依赖不稳定的原生 overscroll。
- 设计范围聚焦在 `App.vue` 和新增组件，没有扩大到首页内容或其它页面。
- 实现路径符合当前 Vue 3 + Vite 项目结构。
- 包含响应式、性能、减少动画偏好、可访问性和编码验证要求。
- 没有未定需求、空白项或互相矛盾的章节。
- 阈值明确为 `65%`，滚轮停止判断默认约为 `150ms`。
- 输入接管只发生在页面底部，且组件端点释放后恢复页面原生滚动。
- 随机呼吸采用确定性参数和 CSS 动画，不增加持续的 JavaScript 多柱动画循环。
